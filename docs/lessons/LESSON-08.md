# 08. Разбор требований на части

Открытый учебный материал; персональные данные и реальные ответы не включены.

Требование может объединять несколько компетенций: например, Git и уверенную параллельную работу через worktree. Общий опыт Git не доказывает конкретную практику. Обслуживание одной базы не доказывает любую SQL/NoSQL-платформу.

Инструкция просит разделять составные пункты, сохраняя обязательность и точные цитаты. Подтверждённая часть должна оставаться видимой, неподтверждённая — иметь своё объяснение. Отсутствие факта в резюме означает `unconfirmed`, а не установленную неспособность.

Структурированное поле `vacancy.work_formats` может обосновать удалённость. Оно не доказывает канал общения или разрешение работать из конкретной страны. Валидатор проверяет допустимость ссылки и значение поля; противоречащий текст всё равно требует смыслового анализа.
