# 03. Поиск по задачам трёх профилей

Открытый учебный материал; персональные данные и реальные ответы не включены.

`config/search_plan.json` содержит три направления и несколько запросов каждого. `load_search_plan` проверяет структуру, `select_query` выбирает один запрос. Посмотреть план без сети:

```powershell
.\.venv\Scripts\python.exe -m examples.fetch_hh_page --list-queries
```

Упоминание Claude или AI само по себе ничего не говорит о подходящести. AI может быть предметом работы, способом разработки или инструментом другой профессии. Поиск даёт кандидатов; содержательная оценка начинается после чтения полных обязанностей и требований.

Одна вакансия может быть обнаружена несколькими запросами. История и дедупликация будущего сервиса должны опираться на ID источника, а не только на название.
