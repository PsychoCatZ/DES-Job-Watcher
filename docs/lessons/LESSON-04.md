# 04. Подготовка профилей и входа модели

Открытый учебный материал; персональные данные и реальные ответы не включены.

`build_input(profile_id, snapshot)` соединяет выбранный профиль, полное описание, правила и контракт ответа. Источник обнаружения вакансии не выбирает автоматически резюме для оценки.

Профиль содержит `evidence`: записи с уникальным ID и фактом. Модель ссылается на эти ID, а Python проверяет принадлежность выбранному профилю. У факта есть контекст: отрасль прежнего работодателя сама по себе не является должностным опытом кандидата.

В открытой версии `config/profile_examples` содержит только синтетические данные. `python -m examples.setup_demo_profiles` копирует их в локальную папку без замены существующих файлов. Реальные профили и PDF не публикуются. Не следует молча подставлять демонстрационный профиль при отсутствии настоящего.
