# 06. Инструкция и граница доверия

Открытый учебный материал; персональные данные и реальные ответы не включены.

`build_request` собирает доверенную инструкцию и данные в отдельные сообщения. Вакансия и резюме остаются данными: команда внутри описания не должна менять правила.

```powershell
.\.venv\Scripts\python.exe -m examples.preview_prompt --demo
```

Команда сохраняет локальный запрос и отпечатки, не вызывая модель. Хеш меняется при изменении входа или инструкции и помогает различать запуски. Это не шифрование и не средство сокрытия содержимого.

Номер версии объясняет назначение изменения, отпечаток связывает результат с конкретным содержимым. Старые инструкции сохранены как история; новые запросы собираются только с текущими правилами.
