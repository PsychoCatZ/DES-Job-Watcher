# 23. Не оплачивать один анализ дважды и выбирать AI-data

`analysis_attempts` в SQLite хранит попытки API отдельно от успешных оценок. Ошибка разбора и таймаут не доказывают отсутствие оплаты, поэтому `analysis_failed` и `in_flight` тоже запрещают автоматический повтор.

Перед запросом `reserve_attempt()` выполняет `INSERT OR IGNORE` по уникальному ключу. Только процесс, вставивший запись, получает право отправить запрос. Это защищает и от двух параллельно запущенных партий. После сохранения ответа статус обновляется; при прерывании остаётся незавершённая попытка. Ложная блокировка после сбоя до отправки возможна — это сознательная осторожность, требуется разбор, а не автоматический повтор.

Ключ включает ID, название, текст, удалённый формат, архивность и выбранный профиль. Смена правил, профиля или сведений о компьютере сама по себе не разрешает оплатить тот же анализ заново. Изменённое содержание вакансии образует новый ключ. Зарплата не входит в него. Это не кэш одного точного API-тела: отпечаток отправленного запроса хранится отдельно.

`import_attempts()` учитывает прежние партии из `data/analysis_batches`: результат или маркер незавершённого запроса означает попытку, а один подготовленный вход — нет. Исходные файлы не меняются. Импорт выполняется локально и может обновлять SQLite даже в запуске без `--live`; сетевых запросов при этом нет. Старые оценки других сценариев вне этого каталога автоматически не импортируются.

`--profile ai_data` в `fetch_hh_details` выбирает только ID, которые пришли из запросов этого профиля. Тот же флаг в `analyze_saved` ограничивает анализ соответствующим резюме. Вакансия при этом не становится подходящей автоматически: происхождение из поиска — лишь выбор кандидатов. Перед LLM отсекаются архивные карточки, точные известные названия исключённого работодателя, оборудование для связи и ранее отклонённые версии.

Пример загрузки:

```powershell
python -m examples.fetch_hh_details --input "data/hh_api/<запуск>/candidates.json" --profile ai_data --limit 20 --live
```

Затем сначала проверить план:

```powershell
python -m examples.analyze_saved --input "data/hh_api/<запуск>/candidates.json" --profile ai_data --limit 5
```

Лишь добавление `--live` ко второй команде запускает до пяти платных запросов. Если ключи установлены в текущем PowerShell, вводить их повторно не нужно.

Тесты проверяют сохранность резерва после открытия базы, невозможность двух резервов одного ключа, блокировку после ошибки, импорт исторических попыток без учёта неоплаченных планов, различение профилей и изменённых текстов.
