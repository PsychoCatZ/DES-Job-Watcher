# 07. Один реальный API-вызов

Открытый учебный материал; персональные данные и реальные ответы не включены.

`openai_adapter.py` содержит `prepare_body`, `analyze_once` и извлечение ответа. `prepare_body` собирает тело запроса без сети; `analyze_once` выполняет один вызов Responses API, затем запускает локальную валидацию.

```powershell
.\.venv\Scripts\python.exe -m examples.analyze_openai --input examples/fixtures/analysis_input.json
```

Без `--live` это проверка сборки. Реальный запрос платный. Скрипт `run_openai.ps1` требует явный `-InputPath`, проверяет вход и только затем просит ключ с маскировкой. Ключ временно передаётся процессу через окружение и не записывается в результат.

Ответ сохраняет статус, фактически возвращённую модель, usage, длительность и отпечатки. Лимит выхода включает reasoning. Автоматических повторов нет: после таймаута неизвестно, обработан ли запрос сервером. Не нужно повторять его вслепую.
