# 01. Окружение, HTTP и JSON

Открытый учебный материал; персональные данные и реальные ответы не включены.

Из корня проекта создаём `.venv` и устанавливаем `requirements.txt`. Отдельное окружение хранит интерпретатор и зависимости проекта; явный путь к `python.exe` позволяет обойтись без активации.

```powershell
.\.venv\Scripts\python.exe examples\search_hh.py
```

В учебном режиме читается `examples/sample_search.json`. `read_text` возвращает строку, `json.loads` превращает её в словари и списки, `print_vacancies` проверяет поля и выводит карточки. JSON `null` становится Python `None`, объект — `dict`, массив — `list`.

Функция `fetch_vacancies` отдельно получает данные по HTTP. `params` задаёт поисковые параметры, `headers` — представление приложения и авторизацию. Сеть включается только через `--live`; токен не нужно писать в коде или истории команд. `with httpx.Client(...)` закрывает клиент при выходе из блока. `raise_for_status` превращает ошибочный HTTP-статус в исключение.

Учебная выдача — кандидаты из поиска, не проверенные рекомендации.
