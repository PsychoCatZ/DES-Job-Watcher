# 02. Снимок страницы и разделение источников

Открытый учебный материал; персональные данные и реальные ответы не включены.

`examples/fetch_hh_page.py` — экспериментальный источник: одна страница поиска и описание одной вакансии. Реальные снимки сохраняются локально в игнорируемой папке `data/snapshots`.

HTML и JSON — разные форматы. Парсер ищет блок состояния страницы и разбирает его содержимое. Сайт может поменять структуру: успешный HTTP-статус не гарантирует, что нужный блок существует. Капча, перенаправление, ограничение частоты или отсутствие данных должны давать ошибку источника, а не пустую успешную выдачу.

Связь списка и карточки проверяется по ID. Это позволяет позже заменить HTML на официальный API, сохранив формат данных для анализа. Доступ через сайт не является доказательством разрешённости любой частоты автоматического обращения. Основной планируемый источник — официальный API с разрешённым доступом.
