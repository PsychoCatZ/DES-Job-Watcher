# 11. Последовательный прогон и отчёт

Открытый учебный материал; персональные данные и реальные ответы не включены.

`prepare_cases` проверяет весь выбранный набор до сети. `run_cases` выполняет анализы последовательно и сохраняет каждый ответ; `write_report` обновляет сводку и список расхождений.

```powershell
.\.venv\Scripts\python.exe -m examples.run_evaluation --manifest examples/fixtures/evaluation/cases.json
```

Это локальная проверка сборки. При живом запуске один HTTP-клиент используется на весь набор. Пока последовательности достаточно, async не нужен.

Исполнитель принимает функцию `analyze(payload)`: в рабочем запуске она вызывает API, в тестах возвращает вымышленный ответ. Такое разделение позволяет проверять файлы и остановку без сети. Ошибка API останавливает прогон; расхождение с ожиданием записывается и не останавливает его. При прерывании остаётся `in_flight`: запрос мог быть обработан. Автоматического возобновления нет.
