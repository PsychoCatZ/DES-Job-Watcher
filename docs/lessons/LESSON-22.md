# 22. Актуальность навыка и решение кандидата

Способность освоить похожий интерфейс не заменяет обязательный ключевой навык высокого уровня. Дополнительная политика версии 2 требует сопоставлять роль навыка в задачах, обязательность, глубину и актуальность практики. Отсутствие сведений не становится доказательством неспособности. Прямое уточнение кандидата о недостаточной текущей готовности является отдельным фактом.

Уточнения актуальности хранятся в локальном `data/private/candidate_facts.json`, а решения по конкретным карточкам — в `data/private/vacancy_feedback.json`. В репозиторий они не входят. Для нового личного анализа факты актуальности добавляются к evidence выбранного профиля с отдельным источником. Резюме и их версии не переписываются.

Решение по карточке привязано к HH ID, профилю, точной цитате и SHA-256 полного описания. Отказ по старой версии не применяется к изменённому описанию или другой вакансии. Слово SQL само по себе ничего не исключает.

При пересчёте `apply_policy()` возвращает отдельный override с источником `explicit_candidate_feedback`. Профессиональный отказ получает `unsuitable/review`: он остаётся в истории профессионального разбора, но не представляется подходящей рекомендацией. Это отличается от `exclude` по недоступной коммуникации. Названия внутренних маршрутов пока не являются интерфейсом Telegram.

`analyze_saved` пропускает уже отклонённую кандидатом пару для точно того же описания до платного запроса. Это не полная дедупликация оплаченных анализов: для других пар она ещё необходима.

Локальный пересчёт не имитирует новую оценку модели. Исторический ответ остаётся без изменений. Новые инструкции версии 2 и новый контекст проверены сборкой, но их влияние на Luna не подтверждено до нового запуска.

Тесты проверяют: отказ действует только на точную пару и описание; изменения текста требуют нового решения; упоминание SQL, включая высокий уровень, не превращается в автоматический отказ при отсутствии обратной связи кандидата. Общую смысловую оценку роли навыка по-прежнему выполняет модель.
