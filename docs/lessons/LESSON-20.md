# 20. Ключи на время окна PowerShell

Запусти `scripts/start_session.ps1` в том же PowerShell, из которого запускаешь Watcher. Скрипт запрашивает HH_ACCESS_TOKEN, OPENAI_API_KEY и HH_USER_AGENT. Секреты отображаются звёздочками. Enter пропускает поле, Ctrl+U очищает ввод, Backspace удаляет символ.

`[Environment]::SetEnvironmentVariable(name, value, 'Process')` устанавливает переменную только для текущего процесса PowerShell. Дочерние Python-процессы наследуют её, поэтому существующие сценарии автоматически находят ключ через `os.environ`. Уже работающий Python не может изменить окружение родительского PowerShell: поэтому настройку выполняет именно PowerShell-скрипт.

Существующие значения не запрашиваются повторно. `-Replace` позволяет ввести замену. Значения не записываются в профиль PowerShell, пользовательские системные переменные или файлы проекта. После закрытия этого окна они не появятся в новом окне. Уже запущенные дочерние процессы сохраняют унаследованную копию до завершения.

Не выводи окружение целиком и не печатай значения этих переменных в терминал. Для очистки без закрытия окна:

```powershell
Remove-Item Env:HH_ACCESS_TOKEN, Env:OPENAI_API_KEY -ErrorAction SilentlyContinue
```

Переменная окружения не является шифрованным хранилищем: её получают дочерние процессы этого окна. Здесь это согласованный способ передать ключи рабочим сценариям на время сессии без повторного ввода.
