# 05. Контракт ответа и проверка

Открытый учебный материал; персональные данные и реальные ответы не включены.

`config/analysis_response.schema.json` описывает допустимый JSON: обязательные поля, типы и статусы. Это контракт между моделью и программой. Модель возвращает разбор; итоговый `decision` вычисляет Python.

```powershell
.\.venv\Scripts\python.exe -m examples.validate_analysis --demo
```

`parse_response` запрещает повторяющиеся ключи и нестандартные JSON-константы. `validate_and_decide` проверяет ID вакансии, профиль, версии, цитаты и ссылки на опыт. Исключение `AnalysisValidationError` означает, что ответ нельзя использовать как оценку. Ошибка обработки не равна вердикту «не подходит».

Наличие цитаты доказывает только её присутствие в тексте, а не правильность вывода. Смысл нужно проверять отдельно.
