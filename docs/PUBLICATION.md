# Публикация и дальнейшие коммиты

Репозиторий содержит исходный код, схемы, версии инструкций, вымышленные примеры, тесты и открытые учебные материалы. Личные данные не являются частью открытой версии.

## Что остаётся локально

- `config/profiles/` — реальные профили и их история;
- PDF-резюме в корне;
- `data/` — снимки вакансий, рабочий корпус, ответы моделей и отчёты;
- `.env*`, ключи, сертификаты, базы, логи, `.venv/`, `tmp/`;
- первоначальные заметки в `docs/`, кроме открытого каталога `docs/lessons/` и этого файла.

`.gitignore` управляет добавлением новых файлов. Он не удаляет секрет из уже созданного коммита. Если секрет опубликован, сначала отозвать/заменить его, затем отдельно решать очистку истории. Личные файлы сохраняются на машине и требуют собственного резервного копирования.

## Один законченный шаг — один коммит

Перед коммитом согласованного изменения: обновить код и соответствующий урок, выполнить тесты, просмотреть diff. Не создавать вымышленную историю разработки: первая публикация содержит текущее состояние и уроки, последующие коммиты отражают реальные следующие шаги.

```powershell
git status --short
git add des_job_watcher examples tests docs/lessons
git diff --cached --stat
git diff --cached --check
.\.venv\Scripts\python.exe scripts/check_publication.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

Сканер проверяет содержимое индекса, а не только рабочей папки. Он находит известные формы ключей, личные адреса/контакты и запрещённые пути; эвристика не является гарантией отсутствия всех возможных секретов. Просмотр diff человеком остаётся необходимым.

Для следующих изменений используйте рабочую ветку и PR, если отдельно не согласована прямая публикация. Факт прошлой публикации не означает автоматическое разрешение всех будущих отправок.

Платные API-вызовы не входят в тесты и не должны включаться в CI. Лицензия пока не выбрана: публичная видимость сама по себе не означает предоставление разрешения на свободное использование кода.
